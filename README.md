## Project 1 Details: Titanic Dataset Analysis

### Task 1: Data Collection & Dataset Understanding

In this task, I loaded the Titanic dataset and explored its structure.

Main steps:

- Loaded the dataset using Pandas
- Displayed the first rows of the dataset
- Checked the number of rows and columns
- Identified the columns and their data types
- Understood what each feature represents
- Checked basic information about the dataset

### Task 2: Data Cleaning & Preprocessing

In this task, I cleaned and prepared the Titanic dataset for analysis.

Main steps:

- Checked for missing values
- Handled missing data
- Removed or handled unnecessary columns when needed
- Checked for duplicate records
- Formatted the data correctly
- Prepared the dataset for analysis

### Task 3: Exploratory Data Analysis

In this task, I analyzed the Titanic dataset to find patterns and insights.

Main steps:

- Calculated basic statistics
- Analyzed survival counts
- Compared survival based on gender
- Compared survival based on passenger class
- Studied the relationship between age, fare, and survival
- Summarized the main findings from the dataset

## Project 2 Details: Students Performance Dataset Analysis

### Task 3: Exploratory Data Analysis

In this task, I analyzed the Students Performance dataset to discover trends and patterns.

Main steps:

- Loaded and checked the dataset
- Displayed dataset shape and columns
- Checked data types
- Calculated basic statistics
- Created helpful columns such as total score and average score
- Compared student performance across different categories

### Task 4: Data Visualization

In this task, I created charts and graphs to communicate insights clearly.

Visualizations include:

- Distribution of math, reading, and writing scores
- Comparison of scores by gender
- Comparison of scores by test preparation course
- Relationship between reading, writing, and math scores
- Charts showing student performance patterns

### Task 5: Predictive Model or Insight Project

In this task, I built a simple predictive model using the Students Performance dataset.

Main steps:

- Selected features for prediction
- Encoded categorical columns
- Split the data into training and testing sets
- Trained a simple machine learning model
- Evaluated the model performance
- Generated insights from the prediction results
